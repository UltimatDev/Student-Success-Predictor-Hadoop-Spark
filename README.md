# 🎓 Student Success Predictor using Hadoop, Spark, and MLlib

A Big Data and Machine Learning project that predicts student academic performance using Hadoop HDFS, Apache Spark, Spark MLlib, and Streamlit.

---

# 🚀 Project Overview

This project analyzes student academic and behavioral data to identify students at risk of failure and provide early recommendations for improvement.

The system uses:

- Hadoop HDFS for distributed storage
- Apache Spark for distributed processing
- Spark MLlib for machine learning
- Streamlit for real-time prediction interface
